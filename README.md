# Vignesh S — Portfolio

A responsive, minimal portfolio made with plain HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Customize
- Replace `assets/vignesh.jpg` to update the profile photo.
- Edit the project placeholder in `index.html` when you have projects to add.
- Update links/contact details in `index.html` as needed.
- The contact form opens the visitor's default email app with a prefilled message. It does not submit to a server; connect a form backend if you want in-page delivery.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, theme and responsive styles
- `script.js` — mobile navigation and contact form behavior
- `assets/vignesh.jpg` — supplied profile portrait
